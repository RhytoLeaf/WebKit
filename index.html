Design tokens

One JSON file (tokens.json) generates every color, type, space, radius, shadow, and motion value. CI regenerates dist/tokens.css and fails the build on drift — tokens are the contract, not the CSS.

Accessibility

  • WCAG 2.2 AA target: semantic roles (role=status/role=alert), label association, aria-invalid + aria-describedby error wiring.
  • Visible :focus-visible rings; all interactive elements are native <button>/<input>.
  • Every semantic color pair verified ≥ 4.5:1 contrast against the surface.
  • prefers-reduced-motion honored site-wide.
  • axe-core runs on every push in CI — see a11y/ACCESSIBILITY.md for the full checklist.
