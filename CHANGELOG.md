# Changelog

All notable changes to WebKit are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/); the project adheres to [Semantic Versioning](https://semver.org/).

## [0.1.0] — 2026-10-28

### Added
- Design-token pipeline: `tokens.json` → `dist/tokens.css` (drift-checked in CI)
- 5 components: `wk-button`, `wk-badge`, `wk-card`, `wk-field`, `wk-notice`
- Documentation gallery (`index.html`) with live Core Web Vitals panel (web-vitals)
- CI quality gates: axe-core (WCAG 2.2 A/AA) + Lighthouse (≥90 all categories) + GitHub Pages deploy
- Accessibility documentation (`a11y/ACCESSIBILITY.md`), contribution standards (`CONTRIBUTING.md`)
